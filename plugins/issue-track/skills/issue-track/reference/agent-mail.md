# Agent Mail: 다른 터미널 작업자의 보고 경로

조율자가 **다른 터미널·다른 기계**의 작업자(최상위 세션)를 띄울 때 보고가 오가는 길이다. 같은 세션의 서브에이전트(`SendMessage`)에는 해당 없다. 예전에는 Orca orchestration 메일함(`orca orchestration send`, `run:<run_id>` 주소)을 썼는데, 터미널 핸들·Run 주소를 지시서에 박았다가 세션을 다시 열 때마다 보고가 끊겨 **Agent Mail**(`agent-mail` CLI)로 바꿨다. 옛 명령은 쓰지 않는다.

## 주소는 역할만

- 주소는 세션·터미널 핸들이 아니라 **역할**이다(예: `myorg/boss`, `<저장소>/coordinator`, `<저장소>/worker-1`). 세션을 다시 열어도 그대로라 작업자·다른 조율자에게 고지할 것이 없다. 지시서·문서에 터미널 핸들, 서버 주소, 토큰을 적지 않는다.
- 역할마다 프로필이 깔려 있다(예: `<저장소>-coordinator`, `<저장소>-worker-1`). 토큰 파일(`~/.config/agent-mail/*.json`)은 열지도 출력하지도 않는다.
- **프로필은 반드시 환경변수 `AGENT_MAIL_PROFILE=<프로필>`로 고른다.** `agent-mail --profile X …`처럼 명령 앞에 쓰면 v0.2.1은 무시한다.

## 작업자: 보내기

```bash
AGENT_MAIL_PROFILE=<저장소>-worker-1 agent-mail send --to <저장소>/coordinator \
  --task <저장소>-<이슈> --subject '[<저장소>-<이슈>] PR #<번호> 열림' --body '<브랜치, tip 해시>'
```

- PR을 열자마자 한 통, 끝나면(병합·정리 뒤, 막혀서 멈출 때도) 보고 한 통. 본문이 길거나 따옴표가 많으면 `--body-file <파일>`.
- 받은 지시에 답할 때는 `reply <ID> --subject 'Re: …' --body '…'`로 같은 스레드에 달고, 끝났으면 `complete <ID>`.
- 성공 출력(`… → … · pending`)을 확인한다. 보낸 뒤 읽혔는지는 `agent-mail outbox`의 상태(pending → read)로 본다.
- **메일은 세션을 깨우지 않는다.** 받는 쪽이 대기 스크립트를 돌려야 알아차린다.

## 조율자: 받기

- 배경 Bash(`run_in_background: true`)로 한 줄만 띄운다. 셸 `&`·`for` 루프·`grep` 필터는 쓰지 않는다.
  ```bash
  agent-mail-wait <저장소>-coordinator 1800
  ```
  내 메일함에 안 읽은(pending) 메일이 생기면 `#ID 보낸이 | 제목`을 찍고 끝나(코드 0) 조율자가 깨어난다. 30분 동안 없으면 코드 3. 읽음 처리는 하지 않으며, 이미 pending이 쌓여 있으면 바로 끝난다.
- 깨어나면 목록의 메일을 `AGENT_MAIL_PROFILE=<저장소>-coordinator agent-mail read <ID>`로 **전부** 읽고 처리한다. read로 바뀐 메일은 대기 스크립트가 다시 알려 주지 않으니 읽고 미루지 말고, 끝낸 것은 `complete <ID>`로 표시한다. 놓친 것 같으면 `agent-mail inbox`(최근 100통)로 본다.
- 작업자를 띄우기 전에 대기가 떠 있는지 본다.

## 화면 폴링 금지

- 작업자 화면을 주기적으로 읽어 끝났는지 보는 감시는 쓰지 않는다. 메일이 안 오면 화면을 읽기 전에 메일 경로(역할·프로필·대기 스크립트)부터 고친다.
- 예외: 작업자를 띄운 직후 「일하는지」 한 번 확인, 대기가 시간 초과(코드 3)로 끝나거나 30분이 지나도록 보고가 없을 때 화면 꼬리를 한 번 읽는다. 화면에 완료 보고가 있고 idle이면 그 화면을 보고로 삼고, 대장 보고에 「작업자 메일 보고 누락, 화면으로 확인」이라고 적는다.

## 새 역할을 쓰기 시작할 때

작업자 쪽에서 시험 메일 하나를 보내 대기가 깨어나는지 본다. 지시서에 주소를 박기 전에 한다.
