# 시험

## 시간 예산

시험 하나는 아래 예산 안에서 끝나야 한다. 넘으면 그 시험은 실패다.

| 종류 | 무엇을 거치는가 | 시험 하나 예산 |
| --- | --- | --- |
| 로직 | 순수 로직만. 네트워크·DB 없음 | 0.5초 |
| 백엔드 | HTTP 요청, DB, 발행 등 서버 경계 | 1초 |
| E2E | 브라우저로 화면을 끝까지 조작 | 3초 |

- 예산은 시험 본문과 그 시험만을 위한 준비(함수 범위 픽스처)를 합친 시간이다. 여러 시험이 나눠 쓰는 픽스처의 준비는 넣지 않는다.
- 시간은 러너의 시험별 소요 시간으로 잰다. 강제하는 곳: `<conftest.py / playwright.config>`.
- 한 시험이 두 종류에 걸치면 더 바깥 경계를 기준으로 분류한다.
- 끝나지 않고 멈추는 시험은 시험별 감시견(`<pytest-timeout 10초>`)이 끊는다.

## 공통 픽스처

- 비싼 준비(콘텐츠 적재, 앱·DB 기동, 브라우저, 로그인 세션)는 세션·모듈 범위로 올리고, 각 시험은 트랜잭션 되돌리기나 복사본으로 격리한다.
- 새 시험을 쓰기 전에 이미 있는 픽스처를 찾는다. 비슷한 준비가 두 번 보이면 합친다.

## 시험 설정

- 타이머·배경 작업 주기·만료는 최소로 하거나 시험이 직접 진행시킨다(가짜 시계, 「한 번 돌기」 호출).
- 비밀번호 해셔는 가장 빠른 것으로 바꾸고, 로그인은 공통 픽스처의 인증된 세션을 재사용한다(로그인 자체를 시험하는 것만 로그인).

## 실패하면 로직을 고친다

- 단언이 실패하면 구현을 고친다. 기대값을 지금 결과에 맞추지 않는다.
- 예산을 넘으면 로직을 최적화한다. 예산 늘리기·시험 쪼개기·단언 줄이기·`skip`은 하지 않는다.
- E2E에서 고정 시간 대기로 통과시키지 않는다. 화면 상태를 기다린다.
- 시험 자체가 틀렸다고 판단되면 혼자 고치지 말고 근거를 들어 확인한다.
